可疑名單逐項檢查
看起來可疑的地方	為什麼其實還是線性
「SUSP 期間 lic 也抓著」	用 life[i][t](0/1)表達生命週期,限制 life ≥ r(有跑就活著)+「life 只准是連續一段」。全是加減不等式
「生命只有一段」(連續性)	ls[t] ≥ life[t] − life[t−1],再 Σls ≤ 1——只有變數相減和加總,線性
「session 活著才抓 slot,最多 n」	K[t] ≤ 4·active[t]——常數乘變數,線性。(變數乘變數才是非線性,這裡的 4 是常數)
「起跑至少 n_min」(彈性)	K[t] ≥ 2·sst[t],同上,常數乘變數
「一格一 slot 做一個 task」	ΣΣ k[h][t] = 8,純加總
makespan 是 max	老招:T ≥ (t+1)·10·r[...] 逐條寫,(t+1)·10 是常數
判斷準則就一句話:每條限制式是不是「變數的常數倍加起來 ≤ / = / ≥ 某數」? 只要沒有出現「變數 × 變數」、平方、max()、if-else,就還在線性世界。上面每一條都通過。

什麼時候才會真的破功?
如果哪天出現這些,才需要搬出查表或 DCA:

變數 × 變數:例如「session 的效率 = 寬度 K × 某個也在變的係數」——K 是變數、係數也是變數,相乘就非線性了。(若係數是常數就沒事)
變數的平方/曲線:像範例 4 的 load²。
連續變數上的階梯:整數值域小可以查表(範例 7 的招),值域大或連續就麻煩。
